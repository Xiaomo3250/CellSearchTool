# 基站工参管理器

一个轻量级的 Web 应用，用于快速管理和查询基站工参信息。支持电信（5G NR / 4G LTE）和联通（5G NR / 4G LTE）等多运营商、多设备商的工参格式自动识别，导入后可通过小区名或 ECI 进行模糊搜索，快速获取关键参数。

## 功能特性

- **多格式自动识别** — 根据文件名和 Sheet 名自动匹配运营商、技术制式和字段映射
- **智能运营商检测** — 基于基站/小区命名规则自动判定运营商归属（电信/联通）及共享状态
- **共享站识别** — 电信工参通过"是否共享"列 + 联通工参通过命名标识 `(LTGX)` 双重机制识别共享站
- **模糊搜索** — 支持小区名、PCI、基站ID、基站名关键词搜索，不区分大小写
- **分页浏览** — 支持分页浏览全部记录，支持页码直接跳转
- **一键导出** — 搜索结果可直接导出为 CSV 文件
- **手动上传** — 支持通过 Web 界面上传工参文件，预览 Sheet 列表后选择性导入
- **数据管理** — 支持按文件/工作表移除数据，支持清空全部数据，自动缓存到本地磁盘

## 支持的工参格式

| 运营商 | 技术制式 | 匹配字段示例 |
|--------|----------|-------------|
| 中国电信 | 5G NR | 基站名称、NR小区名称、gNodeB标识、小区ID、SSB绝对信道号 |
| 中国电信 | 4G LTE | EnodebName、CellName、EnodebID_CELLID、EnodebID |
| 中国联通 | 5G NR | 基站名称、小区名称、基站标识、NR小区标识、PCI |
| 中国联通 | 4G LTE | 基站名称、小区名称、ECI、基站ID |

字段映射采用**多候选列名优先级匹配**，同一字段支持中英文多种列名，兼容华为、中兴、诺基亚、大唐等不同设备商的工参格式。

## 快速开始

### 环境要求

- Python 3.8+
- pandas

### 安装依赖

```bash
pip install pandas openpyxl
```

### 启动应用

```bash
cd 0503-工参管理器
python app.py
```

启动后自动打开浏览器访问 `http://127.0.0.1:18888`

也可以双击 `启动.bat` 一键启动（自动检测 Python 环境、安装依赖、释放端口）。

### 使用方式

1. **手动上传** — 点击页面上方的「导入工参」按钮上传工参文件
2. **选择工作表** — 预览弹窗中勾选要导入的 Sheet（自动推荐相关工作表）
3. **搜索** — 在搜索框中输入小区名、PCI 或基站ID，按回车搜索
4. **浏览** — 分页浏览全部记录，支持页码直接跳转
5. **导出** — 搜索结果可点击「导出结果」下载为 CSV 文件

## 项目结构

```
0503-工参管理器/
├── app.py                  # 后端 API 服务器（~800 行）
├── static/                 # 前端静态文件
│   ├── index.html          # HTML 页面结构
│   ├── css/
│   │   └── style.css       # 样式表
│   └── js/
│       └── app.js          # 前端交互逻辑
├── 启动.bat                # Windows 一键启动脚本
├── uploaded_files/         # 手动上传的工参文件存储目录
├── cache.json              # 磁盘缓存（自动生成）
└── README.md
```

前后端分离：后端专注 API 和数据处理，前端 HTML/CSS/JS 独立维护，便于编辑和版本管理。

## 技术实现

- **后端**：Python 内置 `http.server`，线程安全的数据操作（`threading.Lock`），静态文件独立服务
- **前端**：独立 HTML + CSS + JavaScript，响应式布局，支持列宽拖拽、单元格点击复制
- **数据解析**：pandas 读取 Excel，手动解析 multipart 上传（兼容 Windows）
- **字段映射**：规则引擎 + 多候选列名优先级匹配，具备容错空间
- **运营商检测**：基于基站/小区命名规范的三级优先级智能判定

## 端口配置

默认端口 `18888`，如需修改请在 `app.py` 底部的 `PORT` 变量中更改。

## 注意事项

- 首次启动导入大量工参文件时，数据加载需要数十秒，页面会显示加载进度
- 文件名需包含运营商关键词（电信 / 联通 / 移动）和技术关键词（5G / 4G / LTE / NR）以便自动识别格式
- 清空数据后可重新上传工参文件，不影响后续使用
