# 基站工参管理器

一个轻量级的 Web 应用，用于快速管理和查询基站工参信息。支持电信（5G NR / 4G LTE）和联通（4G LTE）等多运营商、多设备商的工参格式自动识别，导入后可通过小区名或 ECI 进行模糊搜索，快速获取关键参数。

## 功能特性

- **多格式自动识别** — 根据文件名和 Sheet 名自动匹配运营商、技术制式和字段映射
- **模糊搜索** — 支持小区名、ECI / 小区ID 关键词搜索，不区分大小写
- **分页浏览** — 基站目录支持分页，每页显示 20 条记录
- **一键导出** — 搜索结果可直接导出为 CSV 文件
- **自动导入** — 启动时自动扫描 `../0422/工参/` 目录下的 xlsx 文件
- **手动上传** — 支持通过 Web 界面上传新的工参文件
- **数据管理** — 支持清空全部数据后重新导入

## 支持的工参格式

| 运营商 | 技术制式 | 匹配字段示例 |
|--------|----------|-------------|
| 中国电信 | 5G NR | 基站名称、NR小区名称、gNodeB标识、小区ID |
| 中国电信 | 4G LTE | EnodebName、CellName、EnodebID_CELLID、EnodebID |
| 中国联通 | 4G LTE | 基站名称、小区名称、ECI、基站ID |

字段映射采用**多候选列名优先级匹配**，同一字段支持中英文多种列名，兼容华为、中兴、诺基亚、大唐等不同设备商的工参格式。

## 快速开始

### 环境要求

- Python 3.8+
- pandas

### 安装依赖

```bash
pip install pandas openpyxl
```

### 启动应用

```bash
cd 0423-工参管理器
python app.py
```

启动后自动打开浏览器访问 `http://127.0.0.1:18888`

### 使用方式

1. **自动导入** — 将工参 xlsx 文件放入 `../0422/工参/` 目录，启动时自动加载
2. **手动上传** — 点击页面上方的「选择文件」按钮上传工参文件
3. **搜索** — 在搜索框中输入小区名或 ECI，按回车搜索
4. **浏览** — 在基站目录标签页中分页浏览全部记录
5. **导出** — 搜索结果可点击「导出 CSV」下载

## 项目结构

```
0423-工参管理器/
├── app.py              # 主应用（后端 + 前端 HTML）
├── uploaded_files/     # 手动上传的工参文件存储目录
└── README.md
```

整个应用是一个单文件 Python 程序，无需额外的前端构建工具或数据库。

## 技术实现

- **后端**：Python 内置 `http.server`，线程安全的数据操作（`threading.Lock`）
- **前端**：内嵌 HTML + CSS + JavaScript，响应式布局
- **数据解析**：pandas 读取 Excel，手动解析 multipart 上传（兼容 Windows）
- **字段映射**：规则引擎 + 多候选列名优先级匹配，具备容错空间

## 端口配置

默认端口 `18888`，如需修改请在 `app.py` 底部的 `PORT` 变量中更改。

## 注意事项

- 首次启动导入大量工参文件时，数据加载需要数十秒，页面会显示加载进度
- 文件名需包含运营商关键词（电信 / 联通 / 移动）和技术关键词（5G / 4G / LTE / NR）以便自动识别格式
- 清空数据后可重新上传工参文件，不影响后续使用
